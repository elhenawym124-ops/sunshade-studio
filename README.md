# ستوديو الستائر — Sunshade Studio

> **أونلاين:** https://elhenawym124-ops.github.io/sunshade-studio/

أداة إنتاج لورشة ستائر السيارات: مكتبة فريمات بمقاساتها، باترون قماش بمقاس 1:1، وأمر شغل بالتكلفة.

## التشغيل
- افتح `index.html` مباشرة في Chrome أو Edge (بدون سيرفر وبدون إنترنت).
- البيانات تتحفظ في المتصفح (localStorage). خد نسخة احتياطية من زر **تصدير البيانات** كل فترة.

## الأونلاين
- اللينك شغال من أي جهاز، ونفس الملفات اللي بتشتغل محليًا.
- البيانات بتتحفظ في متصفح كل جهاز على حدة؛ للنقل استخدم **تصدير البيانات** ثم **استيراد ملف**.
- المكتبة المشتركة بين كل الأجهزة محتاجة سيرفر/قاعدة بيانات (الخطوة الجاية).

## دورة الشغل
1. **الفريمات**: أدخل الكود، العربية، الشباك، العرض السفلي/العلوي، الارتفاع، أنصاف الأقطار، قطر السلك.
   - استخدم **قالب CSV** لتحميل كل الفريمات مرة واحدة.
   - العرض والارتفاع على **مسار السلك**، مش حرف القماش.
2. **الأطقم**: اختار الفريمات وعدد القطع (4 / 5 / 7) وسعر البيع.
3. **الباترون**: عدّل «الزيادة على الفريم» و«الخياطة من الحرف»، وبعدين:
   - **SVG 1:1** للتصميم أو الطباعة على بلوتر.
   - **DXF** للبلوتر/الكتر (طبقة CUT + SEW + FRAME).
   - **طباعة 1:1 على A4** — الصفحات متقسمة ومترقمة.
4. **أمر شغل**: اختار الطقم والعدد → سلك، قماش، تكلفة، هامش، وطباعة الأمر.

## مهم قبل القص
- في نافذة الطباعة اختار **Scale 100% / Actual size** وليس Fit to page.
- كل صفحة فيها **مسطرة 100 مم** — قسها بالمسطرة؛ لو مش 100 مم بالظبط متقصش.
- القص على خط **CUT** الخارجي. خط **SEW** هو مكان الخياطة.

## الملفات
| ملف | وظيفة |
|---|---|
| `index.html` | الواجهة |
| `geometry.js` | بناء شكل الشباك + offset خط القص/الخياطة |
| `data.js` | التخزين، CSV، حساب الباترون والتكلفة |
| `views.js` | شاشات الفريمات/الأطقم/الباترون/الأمر |
| `exporters.js` | SVG / DXF / طباعة A4 |
| `app.js` | الأحداث والحوارات |

## ملاحظة على البيانات
الأداة مابتجيبش مقاسات عربيات جاهزة — المقاسات دي ملك شغلك. النسخة الأولى فيها 3 فريمات **مثال** (كودها `DEMO-`)؛ امسحها من الزرار الأصفر وحمّل مقاساتك.
